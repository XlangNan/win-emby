织影 Weave

一个把你家的 Emby、音乐库、追更工具、弹幕、一起看…串起来的播放器，一套代码出 Windows、安卓、iPad / iPhone 三个版本。本页讲清楚：每个功能怎么用，每个外部服务怎么搭、怎么接进来。

先说明白：织影本身只是「客户端」。能不能看片，取决于你有没有 Emby 服务器；下面带「可选」标记的依赖都不装也能用，装了才会多出对应功能。每个可选功能的设置入口都在 App 里的 设置 页。

它是什么

Emby 播放器登录 Emby，首页 / 媒体库 / 详情 / 播放，进度与 Emby 账号双向同步。
MPV 内核直接解码原文件：HDR10、杜比视界、MKV、DTS / TrueHD，不依赖服务器转码。
片库发现读 TMDB 看热门影视，一键交给追更服务或 MoviePilot 自动找资源。
音乐对接 Navidrome，歌词、封面、随机推荐、迷你播放条。
一起看 / 一起听多人同步播放视频和音乐，自带中转服务和网页管理后台。
电视直播M3U 订阅或本地文件、多线路自动切换、节目单。

由 Win-box 重构而来，框架是 Tauri 2 + React 19（Windows / 安卓 / iOS 共用同一套界面）。界面有四套皮肤，并支持深色 / 浅色。

整体架构

织影在你的设备上运行，设备直接连各个服务（局域网或你自己的域名），没有任何官方云端。唯一需要你自己再多搭一个的，是「一起看」中转服务。

关键原则：App 里填的地址由设备本机去访问。所以在外网用手机时，凡是你填了 192.168.x.x 的地方都连不上，需要换成能从外网访问的地址，详见 外网访问方案。

安装到设备

三个平台都用 GitHub Actions 自动编译，你不需要在本地装任何开发环境。把项目推到你自己的 GitHub 仓库后：

Windows

  1. 仓库 → Actions → 左侧 build-windows → Run workflow。（推送到 main 也会自动编译。）
  2. 跑完后进入这次运行页面，最下面 Artifacts 下载 Weave-setup，解压得到 织影_x.x.x_x64-setup.exe，双击安装。
  3. 想要正式发布页：打一个 v 开头的标签，安装包会自动挂到 Releases。
git tag v0.2.0
git push origin v0.2.0

系统需要 WebView2（Win10 / 11 基本都自带）。要让显示器真正点亮 HDR，请在 Windows「设置 → 显示 → 使用 HDR」里打开；不打开时 MPV 会把 HDR 片源映射成 SDR，颜色不会发灰。

安卓

  1. Actions → build-android → Run workflow（也可推标签 android-v1.0.0 触发）。第一次约 20–40 分钟。
  2. Artifacts 下载 织影-android，解压得到 织影.apk，发到手机安装。

只编译 64 位 ARM。APK 用仓库里的 android/winemby.keystore 签名，之后每次更新直接覆盖安装；想换签名，就同时换这个文件和工作流里的口令。

iPad / iPhone

  1. Actions → build-ios → Run workflow。
  2. Artifacts 下载 Weave-ios，解压得到 Weave-ios-unsigned.ipa（未签名）。
  3. 用 爱思助手 → 工具箱 → IPA 签名，登录自己的 Apple ID 重签后安装。

免费 Apple ID 签名 7 天过期，到期重新签一次；同时最多 3 个自签应用。iOS 版使用 MPVKit，目前未在大量真机上验证，MPVKit 不可用时会自动退回网页播放器。构建失败请看 Actions 里红色那一步的末尾 50 行日志。

确认装的是哪一版

打开 设置 页，拉到最底部，会显示构建编号（如 1110-A）。反馈问题时请带上它。

第一次使用

  1. 打开 App，登录页填 Emby 地址（如 http://192.168.1.2:8096，用域名就写完整的 https://…）、用户名、密码。App 只保存令牌，不保存密码。
  2. 进入首页后，到 设置 页，从上往下按需配置：
    TMDB → 追更服务 → 弹幕 → MoviePilot → 一起看 → 音乐。每一项都有「保存并测试连接」按钮，显示「连接成功」才算接通。
  3. 不需要的功能留空即可，对应入口会自动隐藏或提示未配置。

功能 · 首页与媒体库

  • 首页：最近添加聚光卡 / 轮播、横版「继续观看」、「下一集」、各媒体库「最近添加」。在 设置 → 首页显示的媒体库 里可勾选显示哪些库、调整顺序，在 首页轮播 里调轮播内容。
  • 「正在一起看」行：配置了一起看服务且有人开房时，首页最上方会出现房间卡片，点一下加入。
  • 媒体库：排序、类型、未看 / 已看 / 收藏筛选，分页加载。
  • 右键 / 长按海报：标记已看 / 未看、收藏。
  • 搜索、收藏、观看历史：都走 Emby 账号，与其它 Emby 客户端互通。

功能 · 详情页

  • 简介、季与单集列表（带剧照、进度、集号）、演职员、相关推荐。
  • 文件信息：大小、帧率、分辨率、编码等。
  • 播放前可选 版本 / 音轨 / 字幕（一部片有多个版本时）。
  • 「更多」菜单：标记已看、收藏、一起看…（配置了一起看服务才出现）。
  • 剧集详情页可 手动扫描片头数据，查看 TheIntroDB 里有没有这一集。

片源直连遇到 403 怎么办

如果你的 Emby 片源是 strm / 网盘直链，MPV 会直接去连那个直链地址。个别直链会校验请求头或时效，出现 403 时 App 会自动重试几次；仍然不行，在播放页的菜单里打开「经 Emby 转发」，让这部片走 Emby 的流（这是手动开关，默认不启用，原则上设备直连）。

功能 · 电视直播

  • 订阅 M3U / M3U8 链接，或导入本地文件；同名频道自动合并多条线路，卡住时自动切线。
  • 收藏频道；可配置 XMLTV 节目单 地址，按 tvg-id 或频道名匹配节目。源和收藏只存本机。
  • 搭建见 直播源与节目单。

功能 · 片库（发现）

MoviePilot 风格的发现页：直接读 TMDB，浏览热门 / 推荐电影与剧集、查看详情与演职员。每部片可以点「想看 / 订阅」，把需求交给两种后端之一：

后端结果需要
追更服务 kuakego-plus自动找资源并转存到网盘（再由 Emby 读到）追更服务
MoviePilot搜索资源并下载到本地MoviePilot

片库本身只需要 TMDB；没配订阅后端时只能浏览，点订阅会提示去设置。

功能 · 音乐

  • 对接 Navidrome：专辑 / 艺人 / 歌单、随机推荐、「随心听」、搜索。
  • 歌词（服务器没有时可自动从 在线来源 匹配）、封面、底部迷你播放条（可显示当前歌词）、全屏播放页。
  • 歌曲「···」菜单：匹配 / 编辑 歌词与封面，修改仅保存在本机。
  • 音乐选项：随机推荐歌曲数（5–300）、随心听歌曲数（10–300）。

功能 · 一起看 / 一起听

多人同步播放同一部视频，或同步听同一份歌单。需要自行部署一个很小的中转服务（零依赖 Node 程序），搭建见 一起看服务。

怎么用

  1. 设置 → 一起看 → 填服务地址 → 保存 → 测试连接。
  2. 视频：详情页 → 更多 → 一起看… → 创建房间（可选公开或私密、是否「等待所有人缓冲」）。播放页里也有「一起看」按钮。
  3. 音乐：全屏播放页的「伴」按钮 → 创建房间。
  4. 别人在首页「正在一起看」行点房间加入，或在设置里输入房间号加入。
  5. 在房间里时，播放页右上角会出现红色 同步播放 按钮，点一下强制对齐到房间当前进度。

规则

  • 同步内容：播放 / 暂停、进度、倍速、换集；音乐还同步播放列表和当前歌曲。
  • 权限：没有该影片所在媒体库权限的用户，看不到这个房间，也无法用房间号加入；房主中途换到他没权限的片子，他会被自动移出（判断依据是 Emby 自己的媒体库权限，不用另外配置）。
  • 一起听：每个人用自己的 Navidrome 账号取歌，所以大家必须连同一个音乐服务器；本机找不到房间里的歌，会自动退出并提示。
  • 房主离开会自动转交；房间无人时自动删除。掉线判断见下面「掉线怎么判断」。
  • 房主可以是任何人；是否所有人都能操作由房间设置决定。

功能 · 其他

  • 多服务器 / 多账号：设置里添加，顶栏一键切换。
  • 四套皮肤 + 深浅色：设置 → 外观；界面字体可自定义。
  • 安卓：系统栏沉浸式透明；TMDB 没有代理时可在设置里写 hosts（域名 → IP）绕过解析问题。
  • 手机 / 平板：悬停样式只在有鼠标的设备上生效，触屏不会出现「点了就一直高亮」。

依赖搭建 · Emby 必需

织影不提供片源，需要你已有一个 Emby Server（或兼容的 Jellyfin 接口，未专门测试）。

要求

  • Emby Server 4.7+，已建好媒体库、已创建用户账号。
  • 设备能访问 Emby 的地址：局域网用 http://IP:8096；外网见 外网访问方案。

用 Docker 装 Emby（群晖等）

services:
  emby:
    image: docker.m.daocloud.io/emby/embyserver:latest
    container_name: emby
    restart: unless-stopped
    network_mode: host
    environment:
      UID: 1000
      GID: 100
      TZ: Asia/Shanghai
    volumes:
      - /volume1/docker/emby:/config
      - /volume1/video:/data/video

启动后浏览器打开 http://群晖IP:8096 完成初始化向导，添加媒体库指向 /data/video。若 DaoCloud 镜像拉不动，把前缀换成你可用的其它国内镜像站（见 国内镜像与代理）。

织影怎么用到它

依赖搭建 · TMDB 与代理 可选

用途：片库（发现）页的数据、TheIntroDB 的查询编号。

  1. 打开 themoviedb.org 注册账号，在「设置 → API」申请。填 v3「API 密钥」或 v4「API 读访问令牌」都行。
  2. App：设置 → TMDB → 粘贴密钥。
  3. 国内直连通常不通，在「代理」里填 HTTP 或 SOCKS 代理，例如 Clash 默认： 
    http://127.0.0.1:7890
  4. 点「保存并测试连接」，提示「连接成功（搜到 N 条）」即可。

手机没有代理怎么办

安卓设置页多出一个 hosts 文本框，写「IP 域名」每行一条，点「插入示例」可以看到格式。填了代理就以代理为准，hosts 不再生效。

有自己的反代 / 镜像域名

点「自定义域名（有反代时用）」，把 API 地址（默认 https://api.themoviedb.org/3）和 图片地址（默认 https://image.tmdb.org）改成你的反代地址。

依赖搭建 · 追更服务 kuakego-plus 可选

用途：在片库里点「想看 / 订阅」，由追更服务自动找资源转存到网盘，再由 Emby 扫入库。织影只负责订阅、取消订阅、查看订阅状态。

  1. 先按 kuakego-plus 自己的说明部署好（建议 1.45.0 及以上，旧版缺少织影用到的接口），记下它的地址端口和 Web 登录账号密码（WEBUI_USERNAME / WEBUI_PASSWORD）。
  2. App：设置 → 追更服务，填：
    项示例
    地址192.168.1.10:8088（不写 http:// 会自动补）
    用户名admin（默认）
    密码你的 WEBUI_PASSWORD
  3. 点「保存并测试连接」，显示「连接成功（kuakego-plus x.y.z）」。

联动路径：织影「订阅」→ kuakego-plus 找资源 → 存入网盘 → 网盘挂载到 Emby（strm 或挂载）→ Emby 入库 → 织影首页「最近添加」出现。其中「网盘 → Emby」这段需要你自己在 NAS 上配置好。

依赖搭建 · MoviePilot 可选

用途：订阅后由 MoviePilot 搜索 PT / BT 资源并下载到本地。要求 MoviePilot v2。

  1. 部署 MoviePilot v2（官方镜像 jxxghp/moviepilot-v2），完成它自己的站点、下载器、媒体库目录配置，并确认它的 Web 界面能正常手动订阅下载。
  2. App：设置 → MoviePilot，地址填 192.168.1.10:3000（不用加 /api/v1）。
  3. 鉴权二选一：
    • 用户名 + 密码（推荐，填 admin 和你的密码）；
    • 或只填 API 令牌，此时「用户名」要留空。
  4. 点「保存并测试连接」，会显示 MoviePilot 里现有的订阅数。

同时配了追更服务和 MoviePilot 时，订阅时可以选择交给哪一个。想保存到网盘选追更，想下载到本机 / NAS 选 MoviePilot。

依赖搭建 · 弹幕聚合服务 可选

用途：播放时按片名自动匹配 B 站、腾讯、爱奇艺、优酷等平台的弹幕。织影对接的是兼容弹弹play v2 接口的聚合服务，例如自建的 danmu_api。

  1. 部署一个弹幕聚合服务（以 danmu_api 为例，镜像名以你实际能拉到的为准）： 
    services:
  danmu-api:
    image: docker.m.daocloud.io/logvar/danmu-api:latest
    container_name: danmu-api
    restart: unless-stopped
    ports:
      - "9321:9321"
    environment:
      TOKEN: "87654321"
  2. App：设置 → 弹幕，服务地址填 192.168.1.10:9321。如果服务设置了 token 路径，就写成带 token 的完整地址，例如 http://192.168.1.10:9321/87654321。
  3. AppId / AppSecret：自建服务留空；只有用弹弹play 官方接口才需要填。
  4. 点「保存并测试连接」。成功后，播放页就会自动加载弹幕，样式（透明度、字号、速度、区域）在播放页里调。

弹幕匹配靠「片名」。Emby 里的片名越规范（中文名 + 年份 + 集号），匹配越准；匹配错了先检查 Emby 元数据。

依赖搭建 · TheIntroDB 片头库 可选

用途：Emby 里没有「片头」章节标记时，用 TMDB 编号 + 季集去在线库查片头 / 片尾时间，用于「自动跳过片头」和「下一集」提示。查询结果缓存在本机，查不到也会缓存，避免反复请求。

  1. 先配好 TMDB（需要它做编号映射）。
  2. 设置 → 播放：打开「自动跳过片头」和「用 TheIntroDB 查片头时间」。

依赖搭建 · 一起看服务 可选

这是织影自带的中转服务，在仓库的 party-server/ 目录。零依赖，只需要 Node 18+，不用 npm install。同时提供网页管理后台。

它做什么

  • 所有设备通过它交换「播放 / 暂停 / 进度 / 换片」等指令；它不转发视频流，每个设备仍然直接从 Emby 取流。
  • 登录验证：App 把 Emby 令牌发给它，它用 EMBY_URL 去 Emby 验证身份、并查询媒体库权限。令牌只存在内存里，不落盘，重启即清空。
  • 房间只存在内存里，服务重启后清空。

方式一：群晖 / 任意 Docker（推荐）

  1. 把仓库里的 party-server 文件夹放到群晖 /volume1/docker/weave-party/。
  2. 编辑里面的 docker-compose.yml，改两处： 
    environment:
  # 群晖上能访问到 Emby 的地址（仅服务端自己用），末尾不要加斜杠
  EMBY_URL: "http://192.168.1.2:8096"
  # 管理网页密码，改成你自己的
  ADMIN_PASSWORD: "改成你的密码"
  TZ: Asia/Shanghai
  3. SSH 登录群晖，执行： 
    cd /volume1/docker/weave-party
sudo docker compose up -d --build
  4. 如果拉基础镜像失败（Dockerfile 默认用国内镜像站），可以改用本机已有的 node 镜像： 
    sudo docker compose build --build-arg BASE=node:20-alpine
sudo docker compose up -d
  5. 浏览器打开 http://群晖IP:8787/admin，输入管理密码，能看到空的房间列表就成功了。（直接访问根地址会自动跳到 /admin。）
  6. App：设置 → 一起看 → 填 http://群晖IP:8787 → 保存 → 测试连接。显示「连接正常…已启用 Emby 登录验证」才对；如果提示「服务端没设置 EMBY_URL」，说明环境变量没生效。

方式二：不用 Docker

cd party-server
EMBY_URL=http://192.168.1.2:8096 ADMIN_PASSWORD=你的密码 node server.js

Windows PowerShell：

cd party-server
$env:EMBY_URL="http://192.168.1.2:8096"; $env:ADMIN_PASSWORD="你的密码"; node server.js

管理网页

地址 http://服务IP:8787/admin。可看所有房间、成员、操作记录；可关闭房间、踢人、切换公开 / 私密；每 2 秒自动刷新。音乐房间带「♪ 音乐」标记。反馈同步问题时，附上这里的操作记录最有用。

外网朋友加入

朋友在外网也要能访问这个服务：把 8787 端口映射出去，或放到反向代理 / 内网穿透后面，朋友的 App 里填外网地址。注意：EMBY_URL 是服务端自己用的内网地址，不要填成外网域名（除非服务端本来就走外网访问 Emby）。

反代示例（Nginx，长轮询需要关闭缓冲和放宽超时）：

location / {
    proxy_pass http://127.0.0.1:8787;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_buffering off;
    proxy_read_timeout 60s;
}

更新服务

只有 party-server 目录里的文件变了才需要重新构建：sudo docker compose up -d --build。只改 App 前端不需要动它。

掉线怎么判断

情况服务端怎么处理
App 被直接关掉 / 手机断网它挂着的长轮询连接会立刻断开；12 秒内没有重新连上，就移出房间，操作记录里写「掉线，已移出房间」
网络闪断、切换 Wi-Fi / 4G客户端毫秒到几秒内会自动重连，在 12 秒内重连则不受影响
失联超过 6 秒（连接断了、也没有心跳）成员列表里显示「离线」；如果房间开了「等待缓冲」，不会再等这个人
房主掉线房主自动转交给房间里仍在线的下一个人
所有人都掉线房间自动删除
手机锁屏 / 切后台、系统冻结了 App按「掉线」处理（连接一断就开始计时）；回到前台后会提示已退出房间，重新加入即可
兜底超过 30 秒没有任何请求，无论如何都移出

同步原理（想排错的人看）

  • 通讯：HTTP 长轮询。GET /api/sync?ver= 在版本变化或 20 秒后返回，POST /api/op 提交操作，GET /api/time 校准各设备时钟。
  • 目标进度 = 暂停时取记录进度，播放时取 记录进度 + 经过时间 × 倍速。
  • 偏差小于 10 秒时微调倍速追上，超过 10 秒才跳转（20 秒冷却），避免来回拉扯。
  • 「等待所有人缓冲」：任一成员缓冲时全房间暂停，单个成员最多拖住 25 秒。

排错 FAQ

登录 Emby 失败

① 地址要带 http:// 或 https:// 和端口；② 手机和 Emby 是否在同一网络，外网要用外网地址；③ 在手机浏览器里先打开该地址，看能不能见到 Emby 登录页。

MPV 起不来 / 黑屏

Windows 需要 src-tauri/lib 里的 libmpv dll（安装包里已带）；起不来时会自动改用内置播放器。也可在 设置 → 播放 → 播放内核 手动切换。

播放卡在转圈 / 提示 403

多见于 strm / 网盘直链。先等待自动重试；仍失败，在播放菜单打开「经 Emby 转发」。注意这是手动开关，默认设备直连。

TMDB 测试连接失败

国内直连不通是正常的：填代理（如 http://127.0.0.1:7890）；安卓没代理可用 hosts；或在「自定义域名」里填你自己的反代地址。

追更 / MoviePilot 测试失败

先在电脑浏览器能打开它们的网页；追更地址不要带路径、MoviePilot 地址不要加 /api/v1；用户名密码错误会明确提示。追更版本太旧时部分接口会 404，升级到 1.45.0+。

弹幕没出来

确认弹幕服务地址（带 token 的要写全）；片名不规范会匹配不到；自建服务 AppId / AppSecret 留空。

一起看：连不上服务 / 提示「服务端没设置 EMBY_URL」

打开 http://服务IP:8787/api/health 看是否返回 ok；没设置 EMBY_URL 请改 compose 后 sudo docker compose up -d --build。

一起看：我的房间别人看不到 / 加不进去

多半是权限：对方的 Emby 账号没有这部片所在媒体库的访问权限，设计上就是看不到。也检查房间是否设为「私密」。

一起看：进度对不上 / 另一台不跟随

先点播放页右上角「同步播放」强制对齐；仍不行，到管理网页复制该房间的操作记录，并说明是哪台设备、怎么调的进度（拖进度条还是快进键），方便定位。

一起听：加入后自动退出

本机的 Navidrome 里找不到房间里的歌，说明和房主不是同一个音乐服务器（或该账号没有这些歌的权限）。

手机上点一下按钮一直高亮

新版已把悬停样式限定在有鼠标的设备上。若仍有，请截图并告知页面名称，反馈时带上设置页底部的构建编号。

安卓上下系统栏颜色不对

新版已改成透明沉浸式。请确认设置页底部构建编号不低于 1109-O。
