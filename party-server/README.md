# 织影 · 一起看 服务

多人同步看片的中转服务。零依赖（只要 Node 18+），不需要 npm install。

## 群晖 Docker 部署（复制粘贴）

1. 把整个 `party-server` 文件夹放到群晖的 `/volume1/docker/weave-party/`
2. 打开 `docker-compose.yml`，改两处：
   - `EMBY_URL`：群晖上能访问到 Emby 的地址，例如 `http://192.168.1.2:8096`
   - `ADMIN_PASSWORD`：管理网页密码
3. SSH 登录群晖，执行：

```bash
cd /volume1/docker/weave-party
sudo docker compose up -d --build
```

4. 浏览器打开 `http://群晖IP:8787/admin`，输入管理密码，能看到空的房间列表就成功了。
5. App：设置 → 一起看 → 填 `http://群晖IP:8787` → 保存 → 测试连接。

> 基础镜像默认走 `docker.m.daocloud.io`。如果拉取失败，把 `Dockerfile` 第 3 行的 `BASE` 换成别的国内镜像站即可。

## 不用 Docker（直接跑）

```bash
cd party-server
EMBY_URL=http://192.168.1.2:8096 ADMIN_PASSWORD=你的密码 node server.js
```

## 外网使用
朋友在外网加入，需要能访问到这个服务：把 8787 端口映射出去（或用反向代理 / 内网穿透），App 里填外网地址。

## 说明
- 登录验证：App 把 Emby 令牌发给本服务，本服务用 `EMBY_URL` 去 Emby 验证；令牌只保存在内存里（用来替用户查询权限），不落盘，服务重启即清空。
- 媒体库权限：没有权限看这部片子的用户，在首页看不到这个房间，用房间号也加不进去；房间中途换到他没权限的片子，他会被自动移出。判断依据是 Emby 本身的媒体库权限，不需要另外配置。
- 房间只存在内存里，服务重启后清空。
- 掉线判断：App 被关掉 / 断网后，长轮询连接断开，**12 秒**内没重新连上就移出房间（房主会自动转交，空房间自动删除）；失联 6 秒起在成员列表显示「离线」，且不再被等待缓冲；30 秒无任何请求兜底移出。
- 管理网页：查看所有房间 / 成员 / 操作记录，可关闭房间、踢人、切换公开或私密。每 2 秒自动刷新。

## 一起听（音乐）
- 音乐房间同步的是：播放列表、当前第几首、进度、暂停。每个人用**自己的 Navidrome 账号**取歌，所以大家的音乐服务器要是同一个。
- 加入时，本机的 Navidrome 里找不到房间正在放的歌（说明不是同一个音乐服务器），会自动退出并提示。
- 房间里谁改了播放列表、切歌、暂停、拖进度，所有人跟着变；歌放完大家同时切下一首，服务端只认第一个。
- 管理网页里音乐房间带「♪ 音乐」标记。
